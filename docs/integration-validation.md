## Detection, tracking and calibrated projection

Evaluation used matching video-hash annotations and IoU ≥0.5. Against the controlled synthetic ground truth, all 30 frames yielded 90 true positives, 0 false positives, 0 missed annotated hazards, mean IoU 0.814, and 0 ID switches. Held-out frames yielded 45 true positives, 0 false positives/misses, mean IoU 0.815 and 0 ID switches. These scores are specific to the controlled scene and should not be extrapolated to lunar footage.

Independently, each actual detected box was matched to an annotation and its detected ground-contact pixel was projected using M2 `observation_to_frame`, never using the ground-truth box as input. On 90 matches, spatial error mean **0.097 m**, median **0.082 m**, p95 **0.193 m**, maximum **0.213 m**; all 90 fell within their reported uncertainty radius. On 45 held-out matches: mean **0.094 m**, median **0.086 m**, p95 **0.182 m**, maximum **0.203 m**. Each of the three truth rocks retained one M1 tracking ID. Source details: `outputs/onnx-live-final/accuracy-all.json`, `accuracy-heldout.json` and `spatial-evaluation.json`. The projection assumes known calibration and a flat ground plane. No accuracy claim is made for uncalibrated NASA footage or real lunar terrain.

## Test status and limits

The full Python suite passed **246**, skipped **5** on the existing pytest 9 interpreter with `CRATER_M2_SOURCE` set to this checkout. M1-specific tests passed **83**, skipped **3**; the M2-specific subset passed **121**. Two optional assistant tests skipped because `pypdf` is absent; the other skips require a large external fixture, a model-specific opt-in flag, or Windows CI provider registration. M3 passed **39** frontend tests with **1 opt-in smoke skipped** by default; the TypeScript production build passed with a bundle-size warning. The separate real M2 WebSocket opt-in smoke passed **1** test when the station allowed 30 s for Vitest to connect. Hosted workflows run portable/model-free checks and do not load the ONNX graph. A first local opt-in smoke attempt expired its 15 s client wait while Vitest started; rerunning with 30 s client wait passed. Do not treat the failed startup window as a detector or contract success.

One Windows-only integration fix allows completed DirectML callback runs to exit after report/socket/producer cleanup instead of hanging in native CRT teardown. It explicitly terminates the completed process on this path; the two-frame and full 30-frame runs exited 0 and a focused regression test covers the condition and output flush. The launcher does not use this path for replay or other devices.

This validates a functional local synthetic-scene demonstration and M1 → M2 → M3 contract. The model has not been field-validated on lunar imagery, and its confidence is not a calibrated probability. Exact detector-input rerun requires the local MP4 and prepared ONNX cache; the tracked small bundle supports independent evidence checks and transport replay only.
