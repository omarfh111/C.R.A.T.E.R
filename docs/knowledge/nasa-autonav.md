# NASA — navigation autonome de Perseverance
Source URL: https://science.nasa.gov/resource/how-perseverance-drives-on-mars/
Verified on: 2026-10-10

Résumé relu de la présentation NASA du 8 avril 2022, pas une copie intégrale.
AutoNav construit des cartes 3D du terrain devant Perseverance, détecte des dangers et choisit un trajet pour contourner les obstacles. Les opérateurs terrestres définissent des étapes ; le rover choisit comment les atteindre. Les dangers évoqués comprennent les rochers, le sable, les cratères et les falaises. Perseverance peut analyser des images pendant son déplacement.

Limite pour C.R.A.T.E.R. : cette description de Mars sert de contexte. Elle ne fournit ni la pose de notre rover, ni la calibration de nos vidéos, ni une validation de notre détection lunaire. Notre assistant explique ; il ne commande pas la navigation.
