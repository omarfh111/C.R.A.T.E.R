# NASA — caméras stéréo et dangers
Source URL: https://science.nasa.gov/mission/mars-2020-perseverance/rover-components/
Verified on: 2026-10-10

Résumé des sections Hazcams/Navcams de NASA Science, page évolutive sans date de publication retenue. Perseverance utilise deux Navcams couleur stéréo sur son mât. Les Hazcams observent notamment les rochers, tranchées et dunes ; des images stéréo permettent d'évaluer le relief avant de conduire.

Application C.R.A.T.E.R. : une boîte 2D de détection ne suffit pas à donner une distance en mètres. Il faut une géométrie et une échelle justifiées (stéréo calibrée, profondeur mesurée ou hypothèse de sol documentée), puis une pose vers LOCAL_ENU_V1. Une vidéo MP4 seule ne garantit pas ces informations. Ce résumé ne valide pas notre reconstruction 3D.
